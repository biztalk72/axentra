    BEFORE YOU START

    체험 전에 알아두세요.

    데모를 어떻게 시작하나요?

    데모 체험 버튼을 누르고 언어를 선택하세요. ‘체험 계정 만들기’로 일반 사용자 계정을 직접 생성할 수 있습니다. 체험 데이터는 현재 브라우저에 저장됩니다.

    공개 데모가 실제 공장에 연결되나요?

    공개 데모는 합성 데이터를 사용하는 브라우저 체험입니다. 실제 설비, CCTV, ERP나 외부 브로커와 연결되지 않습니다. 기기 카메라는 명시적 권한 승인 후 로컬 미리보기로만 사용합니다.

    현장에 맞춰 배포할 수 있나요?

    React·FastAPI·PostgreSQL의 Docker 배포 구성을 제공합니다. 실제 도입 시 설비 어댑터, HTTPS, 인증 정책과 데이터 연동을 현장에 맞춰 구성하고 검증해야 합니다. 현재 제품은 MVP입니다.

# 라인 CCTV

**라인 CCTV**에서 라인·설치 위치·소스 형식·주소·사용 여부·화면 맞춤을 설정한다. 카메라별 설정은 revision으로 충돌을 검사한다. 기본 4개 영상은 합성 SVG 모의 화면이며 실제 카메라가 아니다.

| 위치 | 제공 기능 |
|---|---|
| CCTV 관제 | 전체/A/B 라인 필터, 단일 보기, 멀티뷰, 카메라별/전체 최대화, 최소화·복원 |
| 운영 대시보드 | 사용자별 위젯 사용 여부, 최대 4개 카메라 선택, 단일/멀티뷰·최소화 설정 저장 |
| 현장 패널 | 같은 라인 카메라 최대 4개, 오른쪽/하단 배치, 단일/멀티뷰, 전용 CCTV 화면 |

최대화는 카메라를 복제하지 않고 원래 위치의 플레이어를 해제한다. 최소화·화면 이동도 플레이어를 정리한다. 최대화 보기는 Escape 종료·키보드 포커스 순환을 지원한다. 실제 상태는 media 이벤트로 연결 중/재생 중/오류를 표시하며 오류 시 재시도할 수 있다.

## 영상 연결

- **HLS**: 브라우저 기본 지원 또는 필요할 때 로드하는 hls.js 사용.
- **MP4**: 브라우저 video 재생. 테스트/녹화 영상에도 사용 가능.
- **MJPEG**: 이미지 스트림. 브라우저·게이트웨이의 호환성 확인 필요.
- **RTSP**: 브라우저 직접 재생 대상이 아니다. 현장의 스트리밍 게이트웨이에서 HLS/MJPEG 등으로 변환한 재생 주소를 등록한다.

플레이어가 직접 영상을 요청한다. 백엔드는 영상을 프록시하거나 녹화하지 않는다. 브라우저가 접근 가능한 HTTP(S) 주소, CORS, HTTPS 페이지의 HTTPS 영상 주소가 필요하다. URL에 사용자명·암호를 포함하는 형식은 거부한다. 현장에서는 게이트웨이 인증·짧은 수명 재생 주소·접근 제어를 별도로 구성한다. 카메라 설정이 저장되어 있다는 사실을 실제 영상 연결 성공으로 해석하지 않는다.

Chrome에서 로컬 합성 컬러바를 HLS로 변환해 실제 재생(readyState=4, 640px, 비일시정지)을 검증했다. 최대화 중 video 요소가 하나임도 확인했다. 실제 현장 CCTV 주소·NVR은 제공되지 않아 장비 연동, 장시간 안정성, MJPEG 장비별 호환성은 아직 검증하지 않았다. hls.js는 별도 지연 로딩 청크이므로 Vite의 500KB 청크 경고가 발생할 수 있다.

## Mac·iPhone·iPad 기기 카메라

CCTV 위젯의 **기기 카메라 보기 / Show device camera**를 선택하거나 모의·빈 화면의 **기기 카메라로 보기 / Use device camera**를 누른다. 실제 CCTV 재생 실패 화면에서도 전환할 수 있다. **카메라 켜기 / Start camera**를 누른 뒤 브라우저 권한을 허용하면 영상이 표시된다. 권한 요청은 자동으로 시작하지 않는다.

영상 하단에서 브라우저가 인식한 Mac 내장 카메라·iPhone 연속성 카메라·외장/가상 웹캠을 선택한다. 카메라 목록 새로고침과 끄기 버튼을 제공한다. 권한 거부·카메라 없음·장치 사용 중·장치 해제·비보안 연결은 별도 안내한다. 실패 후 재시도는 시스템 기본 카메라로 복구한다.

iPhone 연속성 카메라는 해당 Mac과 iPhone이 Apple의 지원 조건을 충족하고 브라우저 입력 목록에 나타나야 한다. iPad는 iPad 브라우저에서 이 화면을 열어 직접 카메라를 사용하거나, Mac에 웹캠 입력으로 등록되어 브라우저가 인식하는 연결 방식을 사용한다. 케이블 연결만으로 모든 iPad가 Mac 웹캠으로 자동 인식되는 기능은 제공하지 않는다. 이 기능은 현재 화면을 표시하는 기기의 로컬 입력이며 다른 기기의 영상을 네트워크로 중계하는 서비스는 포함하지 않는다. [Apple의 iPhone 연속성 카메라 안내](https://support.apple.com/en-au/102546).

원하는 라인 패널에 고정 구성하려면 **라인 CCTV → 카메라 등록/설정 → 기기 카메라**를 선택하고 해당 카메라를 대시보드 또는 패널 위젯에 배치한다. source_type=device는 재생 URL을 비우며 물리 deviceId는 서버에 저장하지 않는다. 각 기기에서 실제 입력을 선택하고 권한을 허용한다.

오디오는 요청하지 않는다. 영상은 현재 브라우저의 MediaStream을 video 요소에 연결하며 서버 전송·녹화·저장은 하지 않는다. 최대화 전환은 동일 세션의 스트림을 유지하고, 마지막 뷰가 닫히거나 페이지를 떠나면 트랙을 정리한다. 최소화 이후 다시 켤 때에는 Start camera로 시작한다.

HTTPS 또는 localhost가 필요하다. 다른 기기에서 개발 서버의 일반 HTTP LAN 주소로 접속하면 카메라 API를 사용할 수 없으므로 HTTPS 주소를 사용한다. [getUserMedia 권한·보안 조건](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia).

# 라인 CCTV

**라인 CCTV**에서 라인·설치 위치·소스 형식·주소·사용 여부·화면 맞춤을 설정한다. 카메라별 설정은 revision으로 충돌을 검사한다. 기본 4개 영상은 합성 SVG 모의 화면이며 실제 카메라가 아니다.

| 위치 | 제공 기능 |
|---|---|
| CCTV 관제 | 전체/A/B 라인 필터, 단일 보기, 멀티뷰, 카메라별/전체 최대화, 최소화·복원 |
| 운영 대시보드 | 사용자별 위젯 사용 여부, 최대 4개 카메라 선택, 단일/멀티뷰·최소화 설정 저장 |
| 현장 패널 | 같은 라인 카메라 최대 4개, 오른쪽/하단 배치, 단일/멀티뷰, 전용 CCTV 화면 |

최대화는 카메라를 복제하지 않고 원래 위치의 플레이어를 해제한다. 최소화·화면 이동도 플레이어를 정리한다. 최대화 보기는 Escape 종료·키보드 포커스 순환을 지원한다. 실제 상태는 media 이벤트로 연결 중/재생 중/오류를 표시하며 오류 시 재시도할 수 있다.

## 영상 연결

- **HLS**: 브라우저 기본 지원 또는 필요할 때 로드하는 hls.js 사용.
- **MP4**: 브라우저 video 재생. 테스트/녹화 영상에도 사용 가능.
- **MJPEG**: 이미지 스트림. 브라우저·게이트웨이의 호환성 확인 필요.
- **RTSP**: 브라우저 직접 재생 대상이 아니다. 현장의 스트리밍 게이트웨이에서 HLS/MJPEG 등으로 변환한 재생 주소를 등록한다.

플레이어가 직접 영상을 요청한다. 백엔드는 영상을 프록시하거나 녹화하지 않는다. 브라우저가 접근 가능한 HTTP(S) 주소, CORS, HTTPS 페이지의 HTTPS 영상 주소가 필요하다. URL에 사용자명·암호를 포함하는 형식은 거부한다. 현장에서는 게이트웨이 인증·짧은 수명 재생 주소·접근 제어를 별도로 구성한다. 카메라 설정이 저장되어 있다는 사실을 실제 영상 연결 성공으로 해석하지 않는다.

Chrome에서 로컬 합성 컬러바를 HLS로 변환해 실제 재생(readyState=4, 640px, 비일시정지)을 검증했다. 최대화 중 video 요소가 하나임도 확인했다. 실제 현장 CCTV 주소·NVR은 제공되지 않아 장비 연동, 장시간 안정성, MJPEG 장비별 호환성은 아직 검증하지 않았다. hls.js는 별도 지연 로딩 청크이므로 Vite의 500KB 청크 경고가 발생할 수 있다.

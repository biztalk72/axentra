## 자동 검증의 범위

백엔드는 인증 실패·만료·로그아웃, 서버 권한, source/event_id 중복·지연·유효성·배치 롤백, 임계값 이상 제안, 승인·반려·이중 처리, 시나리오·CSV, 학습·배포·추론·구버전 보관, 가상 AMR 배정·완료, 최종 공정 실적 집계, 라인 중복 시작 방지, 구성 저장·감사·metrics 권한을 검증한다.

PostgreSQL에서는 동시 승인과 동일 로봇의 동시 작업 배정도 검사한다. SQLite는 행 잠금 동작이 달라 해당 4개를 건너뛴다. CI는 두 DB 경로를 모두 실행한다.

Pages 체험 테스트는 브라우저 저장소 기반 데이터 수집 → 시나리오 → 합성 CSV → 모델 학습·배포·추론 → 승인 → 점검 작업 → 가상 로봇 → 감사 이력과 로그아웃·체험 로그인을 검증한다. 실제 서버 인증·권한·동시성 검증의 대체물이 아니다.

현재 의존성의 Starlette/httpx TestClient 사용은 deprecation warning을 출력할 수 있다. 테스트 실패는 아니며 패키지 전환 시 업데이트가 필요하다.

## 검증하지 않은 항목

현장 프로토콜·실설비 제어·실제 고장 예측 정확도·실제 LLM 모델 서비스·물리 엔진·로봇 학습·SSO·다사업장 격리·고부하 성능·생산 가용성·복구 목표는 구현 또는 검증 범위에 포함되지 않는다. 제안된 파일럿 목표를 측정 결과로 해석하지 않는다.

## 계정 흐름 검증 추가

- 관리자 지정 계정으로 Chrome의 Pages 체험 빌드 로그인 확인. 자동 관리자 진입 제거 확인.
- 가입 확인값 불일치 오류, 직접 가입 직후 operator 자동 로그인, 새로고침 로그인 유지, 로그아웃 후 일반 사용자 재로그인, 관리자 승인 버튼 비활성화 확인.
- 실제 Nginx→FastAPI→PostgreSQL에서 관리자 로그인, 구 관리자 이메일 거부, 가입·자동 로그인·로그아웃·재로그인·사용자 목록·일반 사용자 권한 403 확인.
- 계정 검증 오류에서 제출 암호를 반환하지 않음. 새 계정 PBKDF2 해시, 이메일 중복·예약·권한 주입 거부, 가입 비활성화, 관리자 설정 갱신 시 데이터 보존·기존 세션 폐기 테스트.
- 공개 저장소에는 관리자 암호 원문을 포함하지 않으며 로컬 `.env`는 무시한다.

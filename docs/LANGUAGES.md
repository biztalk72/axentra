# 한국어·English UI

로그인 화면의 언어 선택에서 한국어/English를 선택한다. 로그인 후 상단 바와 독립 패널 뷰에서도 전환할 수 있다. 선택값은 이 브라우저의 `forge-ax-locale`에 보관하며 로그아웃·새로고침 이후에도 유지한다. 새 기기에서 특정 언어로 시작하려면 URL의 query에 `?lang=en` 또는 `?lang=ko`를 사용할 수 있다. 명시한 URL 언어는 새로고침 시 브라우저 저장값보다 우선한다.

대시보드·메뉴·폼·접근성 레이블·상태·오류·공급망·에이전트·패널·CCTV 문구와 숫자/시각 표시를 전환한다. 저장된 품목 코드·LOT ID·단위·수량·BOM·패널 구성과 사용자 기록은 변경하지 않는다. 기본 합성 품목/공정/설비명에는 영문 표시를 제공한다. 사용자 정의 작업지시·공지·이름·LLM 자유 서술은 원문 데이터이며 자동 외부 번역하지 않는다. 이름 편집 필드에는 저장된 원문을 표시한다.

## 번역 관리

- `frontend/src/i18n/en.json`: 한국어 원문 키와 영문 표시 문자열.
- `frontend/src/i18n/patterns.json`: 가변 수치·라인·근거가 포함된 문장. `{0}`, `{1}`을 순서에 맞게 사용한다.
- `locale.ts`: 표시 전용 `ui`/`text`, 선택 저장, 문서 lang 및 Intl locale.
- `react.tsx`: 언어 선택과 React 구독.

새 화면의 표시 문구는 `ui(...)`로 감싸고 영문 항목을 추가한다. API 경로·식별자·저장 값·입력 value를 번역 함수로 바꾸지 않는다. `npm --prefix frontend run check:locales`로 정적 UI 문구와 동적 템플릿 누락을 검사한다. 이 검사는 npm test와 CI에 포함된다.

자동 화면 테스트는 메모리 DOM에서 로그인 언어 전환 → 영문 대시보드 → 기기 카메라 권한 거부 안내 → 패널 비교·독립 읽기 모드 → 재고 조회 → 로그아웃 후 영문 유지 흐름을 확인한다. 실제 브라우저 레이아웃 및 카메라 하드웨어 검증과는 구분한다.
